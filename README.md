# Vehicle Detection and Counting

A real-time Vehicle Detection and Counting project built using Python, OpenCV, YOLO, and ByteTrack.

## 🚗 Features

- Detects multiple vehicles in a video
- Detects Cars, Motorcycles, Buses, and Trucks
- Tracks vehicles using ByteTrack
- Counts vehicles when they cross a counting line
- Displays vehicle ID and bounding boxes
- Shows individual vehicle counts
- Displays the total vehicle count

## 🛠️ Technologies Used

- Python
- OpenCV
- YOLO
- Ultralytics
- ByteTrack

## 📂 Project Files

- `vehicle_detection.py` - Main Python program
- `road.mp4` - Input video (not uploaded to GitHub)
- `yolo11s.pt` - YOLO model (downloaded automatically if needed)
